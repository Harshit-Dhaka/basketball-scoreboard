# Basketball Scoreboard

A simple and interactive digital scoreboard web application built as a frontend project to track scores for games.

## Features
* Track scores for both **Home** and **Guest** teams.
* Increment scores by `+1`, `+2`, or `+3` points.
* Reset button to start a **New Game**.
* Custom digital clock/scoreboard font styling.

## Used
* **HTML5**: Page structure and layout.
* **CSS3**: Styling, Flexbox alignment, and custom font integration.
* **JavaScript**: Interactivity, score updating logic, and game reset functionality.
